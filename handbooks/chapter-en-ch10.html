1. Full Detailed Theory

Learning goal: Use correct tags, conditionals and modal meanings in exam sentences.

  1. Question tags copy the auxiliary and reverse positive/negative polarity.
  2. Conditionals show fact, possibility, unreal present, regret or mixed time.
  3. Modals express ability, permission, possibility, advice, duty or habit.
  4. Question tags depend on polarity, auxiliary and pronoun; meaning words such as nobody and few are negative in sense.
  5. Conditionals express different reality levels: fact, real possibility, unreal imagination, past regret and mixed time.
  6. Modal strength matters: might is weaker than may; should advises; must strongly requires.

Question Tags: 15 special rules and 50 practice sentences

A question tag is a short question added to a statement to seek agreement or confirmation. Match the auxiliary, tense, pronoun and positive/negative pattern.

Shortcut: Tag বসানোর আগে বাক্যের subject-কে pronoun-এ বদলাও: Rina → she, books → they, this → it.
Memory trick: Positive line, negative tail; negative line, positive trail.
Common mistakes:
  • ✗ She is ready, is she? → ✓ She is ready, isn’t she?
  • ✗ He does not come, doesn’t he? → ✓ He does not come, does he?
  • ✗ Let’s go, will we? → ✓ Let’s go, shall we?
  • ✗ I am late, am not I? → ✓ I am late, aren’t I?
  • ✗ Nobody came, didn’t they? → ✓ Nobody came, did they?
Exam focus:
  • Add tag: “Rina sings well, ___?” → doesn’t she.
  • Add tag: “They are not late, ___?” → are they.
  • Add tag: “Open the door, ___?” → will you.

Conditionals: zero, first, second, third and mixed

A conditional sentence connects a condition with its result. The verb form tells whether the condition is fact, possibility, imagination or past regret.

Zero Conditional

If/when + present simple, present simple. Use for facts, habits and general truths.

  1. If you heat ice, it melts.
  2. If it rains, the ground gets wet.
  3. If people eat too much, they gain weight.
  4. When the sun sets, it gets dark.
  5. If you mix red and blue, you get purple.
  6. If I drink tea at night, I cannot sleep.
  7. If plants do not get water, they die.
  8. When water reaches 100°C, it boils.
  9. If children are tired, they sleep early.
  10. If you press this button, the light turns on.

First Conditional

If + present simple, will + V1. Use for real possible future results.

  1. If it rains, we will stay home.
  2. If you study, you will pass.
  3. If she calls, I will answer.
  4. If they come early, we will start.
  5. If you work hard, you will improve.
  6. If the bus is late, I will walk.
  7. If he apologises, I will forgive him.
  8. If we save water, we will help the village.
  9. If the shop opens, I will buy a pen.
  10. If you do not hurry, you will miss the train.

Second Conditional

If + past simple, would + V1. Use for unreal or unlikely present/future situations.

  1. If I were rich, I would help the poor.
  2. If she had time, she would learn music.
  3. If I knew the answer, I would tell you.
  4. If they lived nearby, we would meet often.
  5. If he were taller, he would play basketball.
  6. If I were you, I would revise daily.
  7. If it were not raining, we would go out.
  8. If she spoke English well, she would get the job.
  9. If we had a car, we would travel more.
  10. If he studied, he would pass.

Third Conditional

If + past perfect, would have + V3. Use for unreal past situations and regrets.

  1. If I had studied, I would have passed.
  2. If she had called, I would have helped.
  3. If they had left early, they would have caught the train.
  4. If he had listened, he would have understood.
  5. If it had not rained, we would have played.
  6. If I had known, I would have told you.
  7. If she had worked hard, she would have won.
  8. If we had saved money, we would have bought a house.
  9. If he had worn a helmet, he would have been safe.
  10. If you had asked, I would have explained.

Mixed Conditional

Mix past condition with present result, or present condition with past result, when time is different.

  1. If I had studied medicine, I would be a doctor now.
  2. If she had taken the bus, she would be here now.
  3. If they had saved water, the pond would not be dry now.
  4. If I were more careful, I would not have lost the key.
  5. If he were honest, he would not have lied yesterday.
  6. If we were richer, we would have travelled last year.
  7. If she had accepted the job, she would live in Kolkata now.
  8. If I had slept early, I would feel fresh now.
  9. If they were punctual, they would not have missed the train.
  10. If he had trained, he would be stronger now.

Unless vs If not

Unless = if not. Do not use another not after unless in a normal affirmative condition.

  1. Unless you study, you will not pass.
  2. If you do not study, you will not pass.
  3. Unless it rains, we will go.
  4. If it does not rain, we will go.
  5. Unless you hurry, you will miss the bus.
  6. If you do not hurry, you will miss the bus.
  7. Unless he apologises, I will not forgive him.
  8. If he does not apologise, I will not forgive him.
  9. Unless we save water, there will be shortage.
  10. If we do not save water, there will be shortage.
Shortcut: Second conditional-এ “If I were you” পরীক্ষার খুব প্রিয় pattern। Third conditional-এ if + had + V3 এবং would have + V3 জোড়া।
Memory trick: Zero fact, First real; Second dream, Third regret feel; Mixed time two, formula review.
Common mistakes:
  • ✗ If it will rain, we will stay. → ✓ If it rains, we will stay.
  • ✗ If I would be rich, I would help. → ✓ If I were rich, I would help.
  • ✗ If I studied, I would have passed. → ✓ If I had studied, I would have passed.
  • ✗ Unless you do not study, you fail. → ✓ Unless you study, you fail.
  • ✗ If I was you, I would go. → ✓ If I were you, I would go.
Exam focus:
  • Fill: “If you study, you ___ pass.” → will.
  • Fill: “If I ___ rich, I would help.” → were.
  • Fill: “If she had called, I ___ helped.” → would have.
