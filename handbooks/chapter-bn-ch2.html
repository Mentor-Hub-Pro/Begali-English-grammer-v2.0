1. Full Detailed Theory

Learning goal: স্বর, ব্যঞ্জন ও বিসর্গ সন্ধি চিনে সঠিক সন্ধিবিচ্ছেদ করা।

  1. দুটি ধ্বনি মিললে উচ্চারণ সহজ করতে যে পরিবর্তন, সেটিই সন্ধি।
  2. স্বরসন্ধিতে স্বর মেলে; ব্যঞ্জনসন্ধিতে ব্যঞ্জনের রূপ বদলায়।
  3. বিসর্গসন্ধিতে পরের বর্ণ দেখে র/স-জাত পরিবর্তন ধরতে হয়।
  4. সন্ধি ও সমাস আলাদা: সন্ধিতে বর্ণের মিলন, সমাসে পদের মিলন।
  5. সন্ধিবিচ্ছেদে সম্ভাব্য সূত্রের সঙ্গে অর্থপূর্ণ পদ পাওয়া বাধ্যতামূলক।
  6. তৎসম শব্দে সন্ধির নিয়ম বেশি দেখা যায়; প্রচলিত বাংলা শব্দে সব সময় সূত্র খাটে না।

সন্ধির নিয়ম ও উদাহরণ

সন্ধি মানে মিলন। দুটি বর্ণ বা ধ্বনি পাশাপাশি এসে উচ্চারণে যে পরিবর্তন ঘটায়, তাকে সন্ধি বলে। বিচ্ছেদে আবার সেই দুই অংশ আলাদা করি।

দীর্ঘ স্বরসন্ধি (অ/আ + অ/আ = আ)

দুটি অ বা আ পাশাপাশি এলে অনেক ক্ষেত্রে দীর্ঘ আ হয়। প্রথমে দুই পদের মূল ধ্বনি দেখো, তারপর জোড়া লাগাও।

  1. হিম + আলয় = হিমালয়
  2. দেব + আলয় = দেবালয়
  3. বিদ্যা + আলয় = বিদ্যালয়
  4. মহা + আশয় = মহাশয়
  5. ধর্ম + অবতার = ধর্মাবতার
  6. লোক + আচার = লোকাচার
  7. শিব + আলয় = শিবালয়
  8. শোক + আগুন = শোকাগ্নি
  9. সত্য + আগ্রহ = সত্যাগ্রহ
  10. মহা + আত্মা = মহাত্মা
  11. পদ + আঘাত = পদাঘাত
  12. পুষ্প + অঞ্জলি = পুষ্পাঞ্জলি
  13. দশ + আনন = দশানন
  14. দেব + অসুর = দেবাসুর
  15. হস্ত + আঘাত = হস্তাঘাত

গুণ স্বরসন্ধি (অ/আ + ই/ঈ = এ)

অ বা আ-এর পরে ই বা ঈ এলে এ হয়। “অ-ই-এ” এই সিঁড়িটি মনে রাখো।

  1. নর + ইন্দ্র = নরেন্দ্র
  2. গণ + ঈশ = গণেশ
  3. দেব + ইন্দ্র = দেবেন্দ্র
  4. সুর + ইন্দ্র = সুরেন্দ্র
  5. রাজ + ইশ্বর = রাজেশ্বর
  6. মহা + ইন্দ্র = মহেন্দ্র
  7. রাম + ইশ = রামেশ
  8. লোক + ইশ = লোকেশ
  9. দিন + ঈশ = দিনেশ
  10. নাগ + ইন্দ্র = নাগেন্দ্র
  11. গজ + ইন্দ্র = গজেন্দ্র
  12. ধন + ঈশ = ধনেশ
  13. যোগ + ইন্দ্র = যোগেন্দ্র
  14. ভব + ইশ্বর = ভবেশ্বর
  15. জল + ইশ = জলেশ

বৃদ্ধি স্বরসন্ধি (অ/আ + এ/ঐ = ঐ)

অ বা আ-এর পরে এ বা ঐ এলে ঐ হয়। “এলেই ঐ”—এটি দ্রুত চিনতে সাহায্য করবে।

  1. সদা + এব = সদৈব
  2. হিত + এষী = হিতৈষী
  3. মত + ঐক্য = মতৈক্য
  4. জন + এক = জনৈক
  5. তপ + এশ = তপৈশ
  6. ধন + ঐশ্বর্য = ধনৈশ্বর্য
  7. লোক + এষণা = লোকৈষণা
  8. রাজ + ঐশ্বর্য = রাজৈশ্বর্য
  9. মহা + ঐশ্বর্য = মহৈশ্বর্য
  10. প্রজা + এক = প্রজৈক
  11. পদ + এষণা = পদৈষণা
  12. শুভ + এষী = শুভৈষী
  13. ধর্ম + এষণা = ধর্মৈষণা
  14. নব + ঐক্য = নবৈক্য
  15. মন + এষা = মনৈষা

যণ সন্ধি (ই/ঈ → য, উ/ঊ → ব)

ই বা ঈ-এর পরে অন্য স্বর এলে য-ধ্বনি, উ বা ঊ-এর পরে অন্য স্বর এলে ব-ধ্বনি শোনা যায়। বিচ্ছেদে মূল স্বর ফিরিয়ে দাও।

  1. প্রতি + অয় = প্রত্যয়
  2. অতি + অন্ত = অত্যন্ত
  3. ইতি + আদি = ইত্যাদি
  4. যদি + অপি = যদ্যপি
  5. অভি + উদয় = অভ্যুদয়
  6. নি + আস = ন্যাস
  7. সু + অস্তি = স্বস্তি
  8. অনু + এষণ = অন্বেষণ
  9. সু + আগত = স্বাগত
  10. অনু + এষণ = অন্বেষণ

অয়াদি সন্ধি (এ/ঐ/ও/ঔ + স্বর)

এ, ঐ, ও, ঔ-এর পরে স্বর এলে যথাক্রমে অয়, আয়, অব, আব-জাত ধ্বনি হয়। শব্দটি শুনে মাঝের অর্ধস্বরটি ধরো।

  1. নে + অন = নয়ন
  2. শে + অন = শয়ন
  3. গৈ + অক = গায়ক
  4. নৈ + অয়িক = নায়িক
  5. পো + অন = পবন
  6. ভো + অন = ভবন
  7. নৌ + ইক = নাবিক
  8. পৌ + অন = পাবন
  9. হে + অয় = হেয়
  10. দৈ + অ = দায়

ব্যঞ্জনসন্ধি

পাশাপাশি ব্যঞ্জন এলে উচ্চারণ সহজ করতে বর্ণের রূপ বদলায়। আগে শেষ বর্ণ ও পরের প্রথম বর্ণ আলাদা করে দেখো।

  1. দিক্ + অন্ত = দিগন্ত
  2. বাক্ + ঈশ = বাগীশ
  3. জগৎ + নাথ = জগন্নাথ
  4. সৎ + জন = সজ্জন
  5. উদ্ + হার = উদ্ধার
  6. তৎ + ত্ব = তত্ত্ব
  7. বিপদ্ + জনক = বিপজ্জনক
  8. ষট্ + কোণ = ষট্কোণ
  9. বাগ্ + দান = বাগ্দান
  10. উদ্ + গম = উদ্গম
  11. সম্ + কল্প = সংকল্প
  12. সম্ + চয় = সঞ্চয়
  13. সম্ + তোষ = সন্তোষ
  14. নিঃ + তেজ = নিস্তেজ
  15. দুঃ + খ = দুঃখ

বিসর্গসন্ধি

বিসর্গ (ঃ) পরের ধ্বনির প্রভাবে র, স বা অন্য ধ্বনিতে বদলাতে পারে। “নিঃ/দুঃ/মনঃ” দেখলে পরের বর্ণটি আগে দেখো।

  1. নিঃ + তেজ = নিস্তেজ
  2. নিঃ + শব্দ = নিশব্দ
  3. দুঃ + খ = দুঃখ
  4. দুঃ + চিন্তা = দুশ্চিন্তা
  5. মনঃ + তাপ = মনস্তাপ
  6. মনঃ + কষ্ট = মনঃকষ্ট
  7. তপঃ + বন = তপোবন
  8. যশঃ + দা = যশোদা
  9. নিঃ + পাপ = নিষ্পাপ
  10. নিঃ + ফল = নিষ্ফল
  11. দুঃ + শাসন = দুঃশাসন
  12. অন্তঃ + পুর = অন্তঃপুর
  13. বহিঃ + গমন = বহির্গমন
  14. নমঃ + কার = নমস্কার
  15. পুরঃ + কার = পুরস্কার
Shortcut: বিচ্ছেদের শর্টকাট: শব্দের মাঝখানে এ/ঐ/আ দেখলে প্রথমে ভাবো—দুটি স্বর কি মিলেছিল? আর গ্/জ্জ/ত্ত্ব দেখলে ব্যঞ্জনসন্ধির সম্ভাবনা খোঁজো।
Memory trick: স্বর মিলে সুর হয়, ব্যঞ্জনে রূপ বদলায়; বিসর্গ দেখে পরের বর্ণ, ঠিক উত্তরটি মিলায়।
Common mistakes:
  • ✗ দেব + ইন্দ্র = দেবীন্দ্র → ✓ দেব + ইন্দ্র = দেবেন্দ্র
  • ✗ প্রতি + অয় = প্রতিয়য় → ✓ প্রতি + অয় = প্রত্যয়
  • ✗ দিক্ + অন্ত = দিকন্ত → ✓ দিক্ + অন্ত = দিগন্ত
  • ✗ নমঃ + কার = নমঃকার → ✓ নমঃ + কার = নমস্কার
  • ✗ সদা + এব = সদাএব → ✓ সদা + এব = সদৈব
  • ✗ গণ + ঈশ = গণীশ → ✓ গণ + ঈশ = গণেশ
  • ✗ সম্ + কল্প = সমকল্প → ✓ সম্ + কল্প = সংকল্প
  • ✗ সৎ + জন = সতজন → ✓ সৎ + জন = সজ্জন
  • ✗ নিঃ + ফল = নিঃফল → ✓ নিঃ + ফল = নিষ্ফল
  • ✗ অতি + অন্ত = অতিঅন্ত → ✓ অতি + অন্ত = অত্যন্ত
Exam focus:
  • “দিগন্ত”-এর সন্ধিবিচ্ছেদ কোনটি? (ক) দিগ + অন্ত (খ) দিক্ + অন্ত (গ) দি + গন্ত (ঘ) দিক + অন্ত। উত্তর: খ।
  • “সদৈব” শব্দে কোন সন্ধি? (ক) দীর্ঘ (খ) গুণ (গ) বৃদ্ধি (ঘ) যণ। উত্তর: গ।
  • “প্রত্যয়” শব্দটির সঠিক বিচ্ছেদ হল—প্রতি + অয়। এখানে যণ সন্ধি।
  • “নমস্কার”-এ বিসর্গের পরিবর্তিত রূপটি চেনো: নমঃ + কার।
  • সন্ধি বিচ্ছেদে আগে মূল পদের অর্থ মিলিয়ে নাও; শুধু বর্ণ দেখে তাড়াহুড়ো কোরো না।

নিপাতনে সিদ্ধ সন্ধি: দ্রুত বিচ্ছেদ তালিকা

কিছু সন্ধি নিয়মের সাধারণ পথে পুরোপুরি ব্যাখ্যা করা যায় না; এগুলিকে নিপাতনে সিদ্ধ বলা হয়। পরীক্ষায় এগুলি মুখস্থ-ভিত্তিক আসে, তাই তালিকাটি বারবার ঝালিয়ে নাও।

Shortcut: মাঝখানে এ/ঐ/আ বা গ্/জ্জ/ত্ত্ব দেখলে আগে দুটি মূল ধ্বনি আলাদা করো।
Exam trap: শুধু বানান দেখে নয়—বিচ্ছেদের পরে দুই পদের অর্থ হচ্ছে কি না মিলিয়ে নাও।
High-priority focus: সন্ধিবিচ্ছেদ, স্বরসন্ধির সূত্র, ব্যঞ্জনসন্ধির রূপ এবং নিপাতনে সিদ্ধ শব্দ।
